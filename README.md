# AI for HR Lab

Session site for a 90-minute hands-on AI lab with senior HR leaders in Goa.
Everything in `files/` belongs to Monsoon Bay Pharma, a fictional company invented for training.

## Publish on GitHub Pages

1. Create a new repository (public, or private on a plan that allows Pages).
2. Upload everything in this folder, keeping the `files/` folder and the `.nojekyll` file.
3. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
