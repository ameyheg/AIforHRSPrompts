# AI for HR Lab

Session site for a 90-minute hands-on AI lab with senior HR leaders in Goa, facilitated by Amey Hegde.
Everything in `files/` belongs to CureAll Pharma, a fictional company invented for training.

## Publish on GitHub Pages

1. Use the repository `AIforHRSPrompts` (the site URL is case-sensitive: https://ameyheg.github.io/AIforHRSPrompts/).
2. Upload everything in this folder to the repository root, keeping the `files/` folder and the `.nojekyll` file.
3. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute the site is live.
